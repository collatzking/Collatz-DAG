# Collatz-DAG
lean4 verification of Collatz conjecture proof 

📜 Universal Connectivity to One Theorem
Premise 1 (No Loops): Every number has a unique parent step, meaning no repeating loops can ever form in the network.

Premise 2 (Defined Trajectory): The connectivity functions place every positive odd integer onto a track that moves in a clear, proven direction (either directly inward or outward).

Premise 3 (Infinite Flow to Sinks): Every positive odd integer moving along its trajectory must eventually hit a stopping point, known as a sink.

Premise 4 (Unique Root): The number 1 is the only single number whose parent function leads back to itself, making it the only terminal sink in the entire system.

💡 Conclusion
Because every positive odd integer moves along a loop-free path that must land on a sink, and 1 is proven to be the only sink, all positive odd integers must eventually connect to 1.
